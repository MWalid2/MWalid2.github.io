RSA Broadcast Attacks: Håstad, Coppersmith & Miller-Rabin

Breaking textbook RSA without the private key, then showing why OAEP padding stops it.

PythonNumber TheoryMiller-RabinLattice Reduction (LLL)Coppersmith's Method

Overview

A theoretical and experimental study of RSA security in broadcast scenarios: what happens when the same plaintext is encrypted for multiple recipients under the same public exponent. Combines number-theoretic proofs with simulations of the Miller-Rabin primality test, the classical Håstad broadcast attack, and its generalization via Coppersmith's small-root method and LLL lattice reduction.

Problem

Textbook RSA (no randomized padding) is a common simplification in coursework and, historically, in real systems. If a sender broadcasts the same message to several recipients using the same small public exponent e but different moduli, does knowing none of the private keys still let an attacker recover the plaintext, and how does that risk change once the message is padded?

Approach

  1. Generate primes with Miller-RabinImplement the probabilistic Miller-Rabin primality test for RSA key generation, and study experimentally how the number of Miller-Rabin rounds trades off against the probability of misclassifying a composite as prime, and how many random candidates it takes to find an ℓ-bit prime, checked against the Prime Number Theorem's predictions.
  2. Implement Håstad's broadcast attackWhen the same message m is sent to r recipients as ci ≡ me (mod Ni), combine the r congruences with the Chinese Remainder Theorem to recover me mod ∏Ni exactly, whenever me is smaller than that product, then take an integer e-th root to recover m with zero private keys.
  3. Compare integer root extraction methodsImplement and benchmark binary search against Newton-Raphson iteration for extracting the large integer e-th root the attack requires.
  4. Extend the attack to padded messagesGeneralize to linearly padded plaintexts (m'i = aim + bi), reducing the broadcast attack to finding a small root of a polynomial modulo a composite integer, no longer solvable by CRT and an exact root alone.
  5. Apply Coppersmith's method with LLLConstruct a lattice from multiples of the intercepted polynomial, reduce it with the LLL algorithm to find short vectors, and use those to build a new polynomial whose small root recovers the original secret message.
  6. Map the attack's practical limitsRun the generalized attack across different numbers of polynomial multiples (k) and public exponents (e), fitting the empirical relationship between the number of recipients required and e.

Results

Miller-Rabin: the experimental false-positive rate matched the theoretical bound P(error) ≤ 4−t for t rounds, and the average number of random candidates tested before finding an ℓ-bit prime tracked the Prime Number Theorem's prediction.

Root extraction: Newton-Raphson consistently beat binary search, by roughly 10× to 100× for exponents between 20 and 100, consistent with its O(log log X) convergence against binary search's O(log X).

Generalized attack threshold — the critical number of recipients β needed for the Coppersmith-based attack to succeed, as a function of the public exponent e, for different lattice sizes k:

Lattice size kEmpirical threshold β(e)
2β2 ≈ 2.000e
3β3 ≈ 1.475e + 0.450
4β4 ≈ 1.330e + 0.341
5β5 ≈ 1.242e + 0.382
Trade-off: larger k lowers the number of recipients an attacker needs, but the LLL lattice reduction's computational cost grows sharply with k, so the “cheaper in recipients” attack is also the more expensive one to actually run.

Security conclusion, in the project's own words: RSA security does not rely solely on the difficulty of factoring large integers, how the plaintext is padded matters just as much. Deterministic or algebraically structured padding preserves the mathematical relationships Coppersmith's method exploits; randomized, hashed padding schemes like RSA-OAEP break that structure and close the attack off entirely.
