Citrus Production Forecasting

Forecasting citrus yield per hectare from a multi-source agricultural panel.

PythonTime SeriesFeature EngineeringPandas

Overview

A yield-forecasting pipeline for citrus (“agrumes”) production in Morocco's Gharb region, predicting tonnage per hectare from historical harvest records joined against climate, irrigation, and fertilization data.

Problem

Agricultural yield depends on a web of interacting factors, rainfall, irrigation schedule, fertilizer (NPK) application, variety, and parcel-specific soil conditions, spread across separate data sources with no common structure. Turning that into a usable per-parcel yield forecast means solving the data integration problem before the modeling problem even starts.

Approach

  1. Assemble a multi-source panelJoin monthly tonnage records per farm, site, variety, and parcel against five years of irrigation logs, rainfall (“pluviométrie”), climate data, and NPK fertilizer application records.
  2. Engineer domain featuresDerive a theoretical yield baseline per variety, seasonal (“campagne”) encoding, and per-parcel and per-variety effects, structured as dedicated feature modules (climate, irrigation, fertilizer, parcel, variety, time).
  3. Iterate through EDA versionsProgressively refine feature selection and target framing (tonnage per hectare rather than raw tonnage) across multiple notebook iterations, each testing a different feature set or preprocessing choice.
  4. Generate held-out predictionsProduce per-parcel tonnage/hectare forecasts for the held-out campaign, the final step in the modular src pipeline shared with the other production-optimization projects.

Results

This project is exploratory: the repository holds more than half a dozen EDA notebook iterations testing different feature sets and target framings rather than a single finalized benchmark, so no comparison table is reported here.

The pipeline itself, multi-source panel construction across climate, irrigation, and fertilizer data joined to a five-year harvest history, is the reusable part carried forward into the other production-forecasting work in this portfolio.
