Time Series Forecasting

🍊 Citrus Production Forecasting

Forecasting citrus ("agrumes") output from historical production data.

PythonTime SeriesForecastingPandas

Overview

A forecasting pipeline for citrus production, built around historical output data to anticipate future yields.

Problem

Agricultural production planning depends on anticipating yield ahead of the season. Historical output data has to be turned into a forecast that downstream planning can actually use.

Approach

Structured as a modular src package with dedicated data, notebooks, and results directories, mirroring the pattern used across the other production-optimization projects for consistency and reuse.

Results

  • Reusable src-based forecasting pipeline
  • Results layer separating raw output from forecast artifacts
