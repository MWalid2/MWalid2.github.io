Regression

House Price Prediction

Predicting sale price from 80 raw features across 14 organized domains.

PythonRegressionFeature EngineeringXGBoostHyperparameter Tuning

Overview

A regression model for Kaggle's House Prices: Advanced Regression Techniques competition, predicting sale price for 1,460 homes from 80 property attributes.

Problem

With 80 loosely related raw features, ranging from lot shape to garage type, several columns of missing data, and 16 numeric-looking columns that are actually categorical codes, the main challenge is turning a wide, messy feature set into something a regression model can use well, not just picking an algorithm.

Approach

  1. Group features into 14 domainsOrganize the 80 raw columns into location, lot and land, dwelling type, overall quality, age, living space, basement, rooms and layout, exterior, fireplace, garage, comfort systems, outdoor features, and sale context, to structure cleaning and engineering.
  2. Fix feature typing before modelingReclassify 16 numeric-looking columns (OverallQual, MSSubClass, GarageCars, and others) as categorical, since they encode ordinal or nominal categories despite being stored as integers.
  3. Drop collinear and redundant featuresRemove one feature from every pair with |correlation| ≥ 0.8 (keeping the one more correlated with SalePrice), and collapse sum-identity groups like basement square-footage components, 22 columns dropped, 57 kept.
  4. Compare five regression modelsLinear, Ridge, and Lasso Regression alongside Random Forest and XGBoost, all trained on log-transformed SalePrice.
  5. Cross-validate and tune5-fold cross-validation across all five models, then a randomized search over XGBoost's hyperparameters specifically.
  6. Inspect feature importancesConfirm which features actually drive the tuned model's predictions, and check that against the EDA's own findings.

Results

Held-out validation set, log-target RMSE (lower is better):

5-fold cross-validated RMSE (log): Lasso 0.1184 ± 0.0032 (best), XGBoost 0.1205 ± 0.0054, Ridge 0.1207 ± 0.0028, Linear Regression 0.1215 ± 0.0031, Random Forest 0.1359 ± 0.0055. A randomized hyperparameter search over XGBoost reached CV RMSE 0.1172 but only 0.1352 on the held-out validation set (MAE $15,236, R² 0.912), essentially matching the plain, untuned Lasso.

The project's own conclusion: four things account for most of a house's price — overall quality/condition, living space and basement size, neighborhood location, and age/upkeep (year built, remodel year, garage capacity). Bathroom count and lot size add smaller, secondary adjustments on top.
