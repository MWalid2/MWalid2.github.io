Regression

🏠 House Price Prediction

Predicting sale price from 80 raw features across 14 organized domains.

PythonRegressionFeature EngineeringXGBoostHyperparameter Tuning

Overview

A regression model for Kaggle's House Prices: Advanced Regression Techniques competition, predicting sale price for 1,460 homes from 80 property attributes.

Problem

With 80 loosely related raw features, ranging from lot shape to garage type, and several columns of missing data, the main challenge is turning a wide, messy feature set into something a regression model can use well, not just picking an algorithm.

Approach

Grouped the 80 features into 14 domain categories (location, lot and land, dwelling type, overall quality, age, living space, basement, rooms and layout, exterior, fireplace, garage, comfort systems, outdoor features, and sale context) to structure feature engineering and missing-value handling. Modeled with Linear, Ridge, and Lasso Regression, Random Forest, and XGBoost, tuned via K-fold cross-validation with grid and randomized search.

Results

  • Systematic 14-group feature taxonomy applied across 80 raw columns
  • Regularized linear models compared directly against tree ensembles
