Predictive Maintenance

🏭 Predictive Maintenance Pipeline (TNB)

Predicting next-cycle defect occurrence in 33 kV distribution switchgear.

PythonPandasFeature EngineeringMulti-task Learning

Overview

An end-to-end predictive maintenance pipeline built during a Data Science Research Intern role at Universiti Tenaga Nasional (UNITEN), Malaysia, using multi-state utility data from Tenaga Nasional Berhad (TNB) to predict next-cycle recorded defect occurrence in 33 kV distribution switchgear.

Problem

Predictive maintenance only pays off if the pipeline behind it is reliable. Multi-state utility defect and inspection records are noisy and unevenly recorded, and a model built on a badly cleaned dataset will fail silently in production, exactly the risk this benchmark was built to catch before it reaches the grid.

Approach

Structured the project as a sequence of dedicated notebooks: data cleaning handles missing values and outliers in the utility's multi-state records, feature engineering derives lagged and rolling statistics from switchgear inspection history, a modeling stage benchmarks machine learning models for next-cycle defect prediction, and a multi-task stage extends the setup to predict several related failure targets jointly.

Results

  • Reusable, staged data-cleaning and feature-engineering pipeline for multi-state utility data
  • Machine learning benchmark for next-cycle defect occurrence on 33 kV distribution switchgear
  • Multi-task model sharing representations across related failure targets

Publication
