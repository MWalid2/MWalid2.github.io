Object Recognizer: VGG16 Transfer Learning

A from-scratch CNN vs. a VGG16 transfer-learning model on CIFAR-10, quantified.

TensorFlowKerasVGG16Transfer LearningCIFAR-10

Overview

An image classifier for CIFAR-10 (50,000 32×32 color images across 10 classes: airplane, automobile, bird, cat, deer, dog, frog, horse, ship, truck) that benchmarks a from-scratch CNN baseline against a VGG16 transfer-learning model, trained under identical conditions for a fair comparison.

Problem

A basic CNN trained from scratch converged slowly and underperformed on CIFAR-10, motivating a transfer-learning approach instead of further architecture tweaking on the same from-scratch design.

Approach

  1. Load and augment CIFAR-1050,000 32×32 RGB training images across 10 balanced classes, with rotation, zoom, and shift augmentation applied identically to both models.
  2. Train a from-scratch CNN baselineA custom convolutional stack (Conv2D, batch normalization, pooling) trained for 20 epochs as the reference point.
  3. Swap in a VGG16 backboneReplace the custom stack with an ImageNet-pretrained VGG16 base, feeding into a custom head: global average pooling, two dropout-regularized dense layers (2048 units), and a 10-way softmax output.
  4. Train under identical conditionsSame augmentation pipeline, batch size, and 20-epoch budget as the baseline, so any accuracy difference reflects the architecture change, not the training setup.
  5. Ship a desktop GUIA Tkinter app for uploading an image and getting a live class prediction from the trained model.

Results

ModelTest accuracyTest loss
From-scratch CNN63.1%1.089
VGG16 transfer learning85.6%0.677

Transfer learning adds +22.5 percentage points of test accuracy over the from-scratch baseline under an identical training budget, confirming the initial hypothesis: on a dataset this size, ImageNet-pretrained features generalize far better than a small CNN can learn from CIFAR-10's 50,000 images alone.
