🔢 Digit Recognizer (MNIST CNN)

A compact CNN classifying handwritten digits on the classic MNIST benchmark.

TensorFlowKerasCNNMNIST

Overview

A convolutional neural network that classifies handwritten digits (0-9) from 28x28 grayscale images, trained on the MNIST dataset.

Problem

Handwritten digit recognition is a foundational computer vision benchmark, with applications from postal code reading to document digitization, and a good implementation should generalize past the training set's handwriting styles.

Approach

Built a compact CNN (TensorFlow/Keras) with a 16-filter 3x3 convolutional layer, pooling, dropout regularization, and dense output layers, trained on 60,000 images and validated on a held-out 10,000-image test set.

Results

  • High accuracy on the MNIST test set
  • Compact architecture kept intentionally small relative to the dataset size
