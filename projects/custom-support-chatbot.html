LLM Agents

🎫 Custom Support Chatbot: LangGraph Agent

An agentic customer-support assistant with a human-in-the-loop safety layer.

LangGraphLangChainMulti-LLMHuman-in-the-LoopSQLite

Overview

A LangGraph-based customer-support agent, built around a travel-booking use case, that can look up and modify bookings but pauses for human approval before taking any sensitive action.

Problem

Giving an LLM agent direct write access to real systems (bookings, cancellations, payments) is risky without a way for a human to review and approve its intended actions before they execute.

Approach

Built the agent as a LangGraph state machine (an assistant node looping with a tools node) with an interrupt checkpoint before tool execution: the graph pauses, surfaces the proposed action, and waits for the user to approve it or redirect the agent with new instructions passed back as a tool message. Tools are split into modular domains (flights, hotels, car rental, excursions, policy lookup) backed by a local database, and the LLM backend is swappable across OpenAI, Anthropic, Gemini, Mistral, and local Ollama models, with Tavily and DuckDuckGo web search available as additional tools.

Results

  • Working interrupt-and-approve loop for sensitive tool calls
  • 5 modular tool domains backed by a live database
  • Backend-agnostic across 5 LLM providers, including fully local inference via Ollama
