🏢 THINK TO DEPLOY: HR Analytics & RAG Chatbot

Multilingual training analytics and a RAG-based HR chatbot, built for Safran.

PythonRAGSentence TransformersFastAPIStreamlitDocker

Overview

A two-part AI solution built for Safran's HR function: a training-analytics module that mines evaluation feedback, and a retrieval-augmented-generation (RAG) chatbot that answers employee HR questions.

Problem

Safran faced two interconnected HR challenges: extracting actionable insight from training evaluation feedback written in multiple languages, and giving employees fast, accurate access to HR information without exposing sensitive data or relying on external APIs.

Approach

The training-analytics module runs sentiment analysis across French, Arabic, and English feedback, surfaces correlations between satisfaction criteria, and extracts thematic patterns from open comments. The HR chatbot uses retrieval-augmented generation with sentence-transformers embeddings to answer employee questions, adapting responses to the employee's profile. Both components run as independent Docker containers (FastAPI backend, Streamlit frontend) with open-source LLMs executed locally rather than through an external API, dependencies managed per-service with uv.

Results

  • Working proof of concept across both modules, demonstrating technical feasibility
  • Dashboard delivering actionable insight from multilingual training feedback
  • Security-conscious, containerized architecture designed to migrate toward authenticated APIs and production deployment
