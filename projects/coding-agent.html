Coding Agent: Gemini Function-Calling CLI

A sandboxed AI coding agent that reads, runs, and edits files through natural language.

PythonGemini 2.0 FlashFunction CallingStreamlitLLM Agents

Overview

An agentic coding assistant powered by Google's Gemini 2.0 Flash, able to explore a codebase, run Python files, and write or overwrite files entirely through natural-language prompts, available both as a CLI and a Streamlit chat interface.

Problem

Turning a natural-language coding request into safe, concrete file-system actions takes more than a single model call. The agent needs to plan, inspect real files, execute code, and iterate on what it finds, all inside a sandbox that cannot touch anything outside the working directory.

Approach

  1. Send the prompt and history to GeminiEach turn sends the user prompt plus the running conversation history to Gemini 2.0 Flash, which decides whether to answer directly or call a tool.
  2. Dispatch tool calls through one routerA central call_tool function maps the model's chosen tool name to one of four sandboxed operations: list files, read a file, run a Python file, or write/overwrite a file, all resolved as relative paths inside a fixed working directory.
  3. Loop until the model is doneFeed each tool's result back into the conversation and repeat, capped at 20 iterations, until the model returns a final text answer instead of another tool call.
  4. Expose it two waysA CLI entry point for scripted, one-shot use, and a Streamlit chat app with a configurable working directory, verbose token-usage display, and persistent per-session chat history.

Results
