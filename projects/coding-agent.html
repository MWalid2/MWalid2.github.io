🤖 Coding Agent: Gemini Function-Calling CLI

A sandboxed AI coding agent that reads, runs, and edits files through natural language.

PythonGemini 2.0 FlashFunction CallingStreamlitLLM Agents

Overview

An agentic coding assistant powered by Google's Gemini 2.0 Flash, able to explore a codebase, run Python files, and write or overwrite files entirely through natural-language prompts, available both as a CLI and a Streamlit chat interface.

Problem

Turning a natural-language coding request into safe, concrete file-system actions takes more than a single model call. The agent needs to plan, inspect real files, execute code, and iterate on what it finds, all inside a sandbox that cannot touch anything outside the working directory.

Approach

Built around a function-calling loop: the agent sends the user prompt and running conversation history to Gemini 2.0 Flash, lets the model choose from four tools (list files, read a file, run a Python file, write or overwrite a file), executes whichever tool it calls through a central dispatcher, and feeds the result back into the conversation for up to 20 iterations until the model returns a final text answer instead of another tool call. All file operations resolve as relative paths inside a fixed working directory to keep the agent sandboxed. The same agent loop is exposed two ways: a CLI entry point for scripted use, and a Streamlit chat app with a configurable working directory, verbose token-usage display, and persistent per-session chat history.

Results

  • Multi-turn tool-calling loop capped at 20 iterations, the same pattern behind coding agents like Claude Code and Cursor
  • 4 sandboxed file-system tools (list, read, run, write) dispatched through a single router function
  • Two interfaces sharing one agent core: a scriptable CLI and a Streamlit chat UI
